Fridgie is an Android-first Flutter app for tracking expiry dates of food, medicine, and household products.

## Highlights

- Barcode-first product flow (scan -> local catalog -> world catalog -> manual fallback).
- Multi-batch inventory per product.
- Local reminders before expiry (time + lead days configurable).
- Offline-first data storage with SQLite.
- Category presets and local catalog management.
- Backup/restore with ZIP archives.
- MIUI/OEM background reliability guidance.

## Feature Matrix

| Area | Included |

## Backup and Restore

- Backup creates a ZIP archive of database + images.
- Android backup save flow uses file explorer picker.
- Restore stages data swap for next app launch.

## Notifications and MIUI Notes

- App requests notification and exact-alarm related permissions where supported.
- Some OEM ROMs (especially MIUI) can still suppress background alarms.
- Use the in-app Background Reliability page for quick access to:
  - battery optimization settings,
  - app details/autostart,
  - exact alarm settings.
